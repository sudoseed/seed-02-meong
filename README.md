## 작품 소개

멍때리기는 생각보다 어렵습니다. 10초만 지나도 손이 마우스를 찾고, 눈이 알림을 찾습니다.

**멍때림 측정기**는 그 어려운 일을 공문서 톤으로 엄숙하게 측정합니다.
측정이 시작되면 화면 가운데 타이머 뒤로 명상 앱처럼 원이 천천히 숨을 쉬고,
`뇌파 안정도`, `영혼 이탈률`, `현생 거리` 같은 그럴듯한 지표가 실시간으로 바뀝니다.
10초마다 해설진의 진지한 실황 중계도 나옵니다.

> [00:30] 실황 · 점심 메뉴 생각이 감지되었으나 경미합니다.
> [00:40] 실황 · 업계 평균을 넘어섰습니다. 현장이 술렁입니다.

그리고 당신이 무언가를 하는 순간, 화면이 흔들리고 빨간 **실격** 도장이 쾅 찍힙니다.

## 사용법

1. **피험자 이름**을 적습니다. (선택, 비우면 `익명의 피험자`)
2. 빨간 **[ 측정 시작 ]** 버튼을 누릅니다.
3. `3… 2… 1… 멍.` 이후 측정이 시작됩니다. **아무것도 하지 마세요.**
   - 시작 후 1초는 버튼을 누른 손이 떨려도 봐 드립니다.
   - 생각은 허용됩니다. 단, 티 내지 마십시오.
4. 실격되면 **공식 측정 결과지**가 발급됩니다.
   - **결과 복사**: `멍때림 측정 결과: 멍 3단 (47.32초) · 실격 사유: 마우스 이동 · 너도 해봐 → 주소` 형태로 복사됩니다.
   - **이미지로 저장**: 관인이 찍힌 결과지를 PNG로 저장합니다.
   - **다시 측정**: 바로 다음 측정을 시작합니다.

## 등급표

| 기록 | 등급 | 심사평 |
|---|---|---|
| 5초 미만 | 멍 입문자 | 멍의 문턱에서 발이 걸렸습니다. 아무것도 안 하는 것도 재능이며, 그 재능은 아직 잠들어 있습니다. |
| 5–15초 | 멍 1단 | 가능성은 보입니다. 다만 현생이 아직 피험자의 소매를 강하게 붙잡고 있습니다. |
| 15–30초 | 멍 2단 | 눈의 초점이 풀리기 시작했습니다. 심사위원회는 이 조용한 성장을 주목하고 있습니다. |
| 30–60초 | 멍 3단 | 1분의 벽 앞까지 도달했습니다. 평소 회의 시간에 꾸준히 수련해 온 흔적이 역력합니다. |
| 60–120초 | 멍 사범 | 타인에게 멍을 가르칠 자격이 인정됩니다. 단, 가르치려고 입을 여는 순간 실격입니다. |
| 120–300초 | 인간 화분 | 광합성 외의 활동이 관측되지 않았습니다. 물을 주고 싶다는 민원이 다수 접수되었습니다. |
| 300초 이상 | 해탈 | 심사위원회는 더 이상 피험자를 측정할 수 없습니다. 측정기가 피험자를 존경하기 시작했습니다. |

## 실격 사유 (일부)

움직인 방식에 따라 사유가 구체적으로 기록됩니다.

| 한 일 | 결과지에 적히는 사유 |
|---|---|
| 마우스를 살짝 움직임 | 마우스 3px 이동 (피험자의 욕심) |
| 마우스를 크게 움직임 | 마우스 240px 이동 (명백한 현생 복귀 의지) |
| 오른쪽 클릭 | 마우스 오른쪽 클릭 (메뉴에 대한 호기심) |
| ESC | ESC 키 입력 (탈출 시도) |
| 스페이스바 | 스페이스바 입력 (공허를 채우려는 시도) |
| F5 / Ctrl+R | 새로고침 키 입력 (인생 리셋 욕구) |
| 한/영 키 | 한/영 키 입력 (정체성 혼란) |
| 휠 아래로 | 마우스 휠 아래로 굴림 (피드를 내리던 습관 재발) |
| 화면 터치 | 화면 터치 (손가락의 반란) |
| 다른 탭으로 이동 | 탭 이탈 (현생 복귀 시도) |
| 다른 창 클릭 | 창 이탈 (다른 창으로 도피) |

## 실행 방법

- **인터넷으로**: https://sudoseed.github.io/seed-02-meong/ 에 접속합니다.
- **내 컴퓨터에서**: 저장소를 내려받고 `index.html`을 브라우저로 엽니다. 설치할 것은 없습니다.

휴대폰에서는 측정 중 화면이 꺼지면 탭 이탈로 실격됩니다. 지원하는 브라우저에서는 측정 중 화면 꺼짐을 자동으로 막아 둡니다.

## 이렇게 만들어졌습니다

- **순수 HTML / CSS / JavaScript**. 빌드 도구, 프레임워크, 외부 라이브러리가 없습니다.
- **서버, 로그인, 유료 API 없음**. 모든 측정은 브라우저 안에서만 이뤄지고, 이름과 기록은 어디에도 전송되지 않습니다.
- **개인 최고 기록**은 브라우저의 `localStorage`에만 저장합니다. 저장할 수 없는 환경(사생활 보호 모드 등)에서도 앱은 정상 동작합니다.
- **결과지 이미지**는 라이브러리 없이 `canvas`에 직접 그립니다.
- **애니메이션 3종**: 측정 수칙 터미널 타이핑과 깜빡이는 커서, 타이머 뒤에서 숨 쉬는 원형 파동, 실격 순간의 화면 흔들림과 도장 날인. 기기에서 '동작 줄이기'를 켜 두면 셋 다 끄고 바로 표시합니다.
- 글꼴: [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) · [Nanum Gothic Coding](https://fonts.google.com/specimen/Nanum+Gothic+Coding) (터미널 UI), [Noto Serif KR](https://fonts.google.com/noto/specimen/Noto+Serif+KR) (제목·결과지). Google Fonts에서 불러오며, 불러오지 못하면 기본 글꼴로 표시됩니다.
